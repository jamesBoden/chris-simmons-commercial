# Chris Simmons Commercial — static website

A simple HTML/CSS website suitable for GitHub Pages.

## Files
- `index.html` — website page
- `styles.css` — styling and responsive layout
- `assets/chris-simmons-commercial-logo.png` — supplied logo artwork

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (not just the ZIP file).
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide the published website address.

## Before publishing
The supplied Chris Simmons Commercial billboard artwork is the definitive brand reference and is used directly as the website masthead. The website uses the burgundy and gold palette from that artwork throughout. The office address is shown as 161 High Street, Ruislip, Middlesex, HA4 8JY; please check the contact details before launch.

The introductory copy describes publicly listed services only. No unverified personal biography, testimonials, awards or current property listings have been added.

The hero section uses the billboard's burgundy and gold brand colours rather than unrelated stock photography, so the site identity stays consistent with the existing billboard.
